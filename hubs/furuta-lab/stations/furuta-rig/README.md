# furuta-rig

`Furuta.Rig` (`../../model/Furuta.mo`) as a Simplicial station, generated by
`articula generate model/Furuta.mo --model Furuta.Rig` (path: fmu, since the amplifier's dead band is an event).

- Station: one `rig` object; its props are the model's top-level parameters (`deadband`, `umax`,
  `alpha0`, the pendulum's start: π hangs it). The true parameters sit inside it, hidden.
- Flow: its linked block takes `cmd` (V) and gives `theta` and `alpha` (rad).

Changed by hand after generating (generate doesn't write toolkits yet): `descriptor.toml` imports
`base`, `step`, `control` and `optimization`; `main.cpp` registers the control and optimization
toolkits and `CMakeLists.txt` links them. Build with Simplicial and `paperboat toolkit install control`
(it brings optimization). `../furuta-rig-0.1.0.pst` is this folder packed (`paperboat pack`).
