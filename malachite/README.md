# Malachite examples

Standalone [Paperboat Malachite](https://github.com/paperboatlab/malachite) hubs: folders of Markdown
notes, each checked so that it renders and its index and links resolve. The set is ex#49; hubs that
use every app are in [`hubs/`](../hubs/). Back to the [repository](../README.md).

Each folder is a hub (`.malachite/hub.toml` and its notes; open it with
`paperboat app open malachite <folder>`), with its golden file and an `example.toml`
([golden tests](../docs/golden.md)).
