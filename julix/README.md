# Julix examples

Standalone [Paperboat Julix](https://github.com/paperboatlab/julix) folders, a set to learn Julix
from: notebooks and scripts, JulixBase and JulixPlot, and at least one that uses a package from
the General registry (CasADi through CasADiNative.jl) in the folder's own environment. The set is
ex#45. Back to the [repository](../README.md).

Each folder is a Julix folder (open it with `paperboat app open julix <folder>`) with its
`Project.toml` and `Manifest.toml`, a script that writes its results, the golden file and an
`example.toml` ([golden tests](../docs/golden.md)).
